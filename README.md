🛒 Blinkit Clone

A frontend clone of the popular Blinkit grocery delivery platform built using HTML, CSS, and JavaScript.
This project replicates key features such as Login/Signup, Product Listing, Cart, and Checkout with a simple and responsive UI.

🚀 Features

✅ User Authentication

Login & Signup pages (Email/Password form-based)

(Future) Google Login & Phone OTP support

✅ Homepage

Search bar

Product categories & banners

Product grid with “Add to Cart”

✅ Cart & Checkout

Add, remove, and update product quantity

Cart summary with total price

Checkout form with delivery details & payment options

Order success screen

✅ User Experience

Responsive design (works on desktop & mobile)

LocalStorage used for storing cart items & orders

Simple, clean UI inspired by Blinkit

🏗️ Tech Stack

HTML5 – Structure

CSS3 – Styling (Flexbox, Grid, Responsive Design)

JavaScript (ES6) – Functionality (Cart, Checkout, LocalStorage)

(Optional) Firebase – Google Login & Phone OTP

⚡ How to Run

Clone the repository

git clone https://github.com/himanshuraghorteatwork/BLINKIT_CLONE.git
cd blinkit-clone


Open index.html in your browser.

Explore login, signup, cart, and checkout flow.
